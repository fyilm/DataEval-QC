# 评测集版本变更记录

> 评测集一旦冻结，任何变更必须在此登记，并说明变更原因与影响范围。
> 冻结的意义在于：所有历史指标可比。改了评测集就等于换了尺子，此前的数字不能直接对比。

---

## eval_v1 — 2026-09-28（当前版本）

**首次冻结。** 由 `src.evalset` 在 seed=42 下生成，产物为 `data/eval/eval_v1.jsonl`。

- 规模：**1400 张**
  - 分层抽样 1200 张
  - 长尾补录 200 张
- 分层格：**57 格全部填满**（未填满格 0 个）
- 抽样 seed：**42**
- 长尾构成：backlit / rain_fog / smudge / smear / dark_compressed 各 40 张
- 长尾来源约束：**必须来自与评测池相同的母图集合**，避免引入新的泄漏

### 分层网格

缺陷类型 7（6 类 + normal）× 场景 3（indoor / outdoor / night）× 难度 3（easy / mid / hard）= 57 格。
配额算法：等额起步 + 缺额回补（详见 [`sampling_spec.md`](sampling_spec.md)）。

### 与 split 的关系

`src.split` 先预留出 eval 池（221 个母图组、1600 个样本），`src.evalset` 再从这个池里抽样。
池里未被抽中的样本**既不参与训练，也不属于冻结评测集**。
（注意区分：`data/manifest.jsonl` 里 `split=eval` 有 1600 条，那是池；冻结评测集是 1400 条。）

### 已知问题

- 场景分布不均（outdoor 占 64.6%、indoor 仅 15.1%），部分分层格的可选样本很少，
  只能靠"缺额回补"从相邻格借样本，个别格的样本量偏小。
- 长尾 5 类每类仅 40 张，统计上偏薄，只适合做定性观察，不适合算显著性指标。

## 变更模板

后续若需变更，按此格式登记：

```
## eval_v2 — YYYY-MM-DD

变更原因：<为什么改，是发现标注错误、还是补充覆盖、还是口径调整>
影响范围：<新增/删除/重标了多少张，影响哪些分层格>
可比性说明：<与 v1 的指标能否直接对比，不能的话差在哪里>
```

**原则上不修改已冻结的 eval_v1**，而是新增 v2 并在报告中并列两个版本的数字。
