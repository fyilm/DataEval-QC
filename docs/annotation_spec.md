# 标注规范（annotation_spec）

> 版本 v1.0 ｜ 冻结日期 2026-09-28
> 本文件是六类缺陷判定的唯一口径。改判定边界必须新增版本号并同步 `evalset_changelog.md`。

## 0. 总则

1. **多标签**：一帧可同时命中多类。例：低码率夜景可能同时命中 `dark` + `noise`。
2. **判定依据是"结果"，不是"成因"**。标注员只看画面呈现的画质现象，不猜测拍摄条件。
3. **轻微程度（mild 档）的边界样本人工作为难例单独归档**，见第 3 节。
4. 标注员之间不得互相看对方的标注结果（独立性），不一致样本进仲裁。

## 1. 六类判定边界

### 1.1 low_res 低分辨率

| 项 | 内容 |
|---|---|
| 判定要点 | 实际有效分辨率低于标称；有降采样再放大的痕迹 |
| 正例特征 | 边缘振铃、文字/纹理糊成块、直线呈阶梯状、高细节区域明显"塑料感" |
| 反例 | 原生低分辨率监控流（按业务口径本就如此，不算缺陷）；运动模糊导致的细节丢失 |
| 与 blur 的边界 | **看纹理是否被"块状"替代**：low_res 有像素块/锯齿，blur 是连续的涂抹感 |
| 边界规则 | 能看清人脸轮廓但看不清五官 → 命中；整帧无任何可辨细节 → 同时命中 low_res + blur |

### 1.2 blur 模糊

| 项 | 内容 |
|---|---|
| 判定要点 | 运动模糊或失焦 |
| 辅助指标 | 拉普拉斯方差 `cv2.Laplacian(gray, CV_64F).var()`，低于阈值辅助判断（不作为唯一依据） |
| 正例特征 | 运动方向拖影、整体失焦、焦点落在背景而主体糊 |
| 反例 | 浅景深但主体清晰；low_res 的块状伪影 |
| 与 low_res 的边界 | blur 是连续模糊，无像素块；**两者可同时命中** |
| 边界规则 | 主体清晰、仅背景虚化 → 不命中 |

### 1.3 over_expo 过曝

| 项 | 内容 |
|---|---|
| 判定要点 | 高光溢出、局部细节丢失 |
| 正例特征 | 天空/灯源/反光面变成纯白无层次、高光边缘出现光晕 |
| 反例 | 画面中本来就有的白色物体（白墙、白衬衫）但层次分明 |
| 边界规则 | 只要有**任一区域**高光溢出且细节丢失即命中，不要求整帧过曝 |

### 1.4 dark 欠曝 / 黑屏

| 项 | 内容 |
|---|---|
| 判定要点 | 整体过暗或近纯黑帧 |
| 正例特征 | 大部分区域亮度低到无法分辨内容、暗部细节全部丢失 |
| **夜视边界（重要）** | **夜视场景下画面整体偏暗属正常曝光，不命中 `dark`。** 判定标准是"细节不可辨"，不是"绝对亮度低"。一张夜视帧若能看清行人轮廓和主要结构，即使 mean_lum 只有 40 也不算 dark |
| 反例 | 夜视正常曝光帧；逆光但主体剪影可辨（那种情况标 `over_expo`，因为背景过曝是主要缺陷） |
| 边界规则 | 若同时存在大面积过曝区和欠曝区（典型逆光），**同时命中 over_expo + dark** |

### 1.5 occlusion 遮挡 / 污渍

| 项 | 内容 |
|---|---|
| 判定要点 | 画面被异物部分遮挡、镜头污点 |
| 正例特征 | 前景异物（雨滴、泥点、手指、胶带）、镜头脏污造成的固定暗斑/光斑 |
| 反例 | 画面内容本身的遮挡（人站在柱子后面）；雾/霾导致的全局对比度下降 |
| 边界规则 | 遮挡面积 < 画面 3% 且不遮关键区域 → 不命中 |

### 1.6 noise 压缩噪声

| 项 | 内容 |
|---|---|
| 判定要点 | 低码率块效应、JPEG 蚊式噪声 |
| 正例特征 | 8×8 块状边界、平坦区色带、高频纹理区的蚊式噪点 |
| 反例 | 传感器高斯噪点（随机散布、无块状结构）；low_res 的像素块 |
| 与 low_res 的边界 | 块效应在**平坦区域**也可见 → noise；只有边缘处有块 → 更可能是 low_res |
| 边界规则 | 两者常同时出现（低码率通常也低分辨率），命中即都标 |

## 2. 优先级与冲突消解

当多个类别疑似成立时，按以下顺序判断（先判结构性缺陷，再判全局画质）：

```
occlusion（结构性，最客观）→ dark / over_expo（全局亮度，互相排斥时看哪个更严重）
→ low_res（有块状伪影）→ noise（平坦区有块效应）→ blur（连续模糊）
```

- **dark 与 over_expo 不互斥**：逆光帧两者都命中。
- **low_res 与 noise 高度共现**：允许同时命中。
- **blur 与 low_res 互斥倾向**：连续模糊优先标 blur；若同时有明显像素块则都标。

## 3. 难例处理

- 轻微（mild 档）样本单独打 `hard` 难度标记，进入难例子集。
- 双人标注不一致的样本进入仲裁队列，仲裁结果**回写规范**：若某类边界规则导致不一致率 > 15%，视为规范缺陷，需修订规范并重标该类。
- 长尾样本（逆光、雨雾、污渍）单独归档在 `data/eval/longtail/`，状态为待人工复核。

## 4. 一致性度量

- 双人独立标注重叠样本，计算 **多标签 Cohen's Kappa**（逐类二元 Kappa 后 macro 平均）。
  多标签不能直接套单标签 Kappa 公式，实现见 `src/agreement.py`。
- 目标：macro Kappa ≥ 0.85。
- VLM 预标注与规则标签比对，不一致样本自动进人工复核队列（`data/review_queue.csv`），
  复核量下降比例写入报告。

## 5. 生成侧参数（供追溯）

真实帧的"清晰"判定阈值（采集阶段筛查用，不是标注阈值）：

| 参数 | 值 | 说明 |
|---|---|---|
| `MIN_SIDE` | 320 px | 短边下限 |
| `MAX_LONG_SIDE` | 960 px | 长边超限等比缩放 |
| `MIN_LAPLACIAN_VAR` | 80.0 | 低于视为天然模糊 |
| `MEAN_LUM_RANGE` | [45, 225] | 常规帧平均亮度区间 |
| `NIGHT_LUM_RANGE` | [18, 88] | 夜间帧放宽亮度 |
| `NIGHT_MIN_LAPLACIAN_VAR` | 60.0 | 夜间帧清晰度阈值放宽 |

> 这些是**采集筛查**口径，与第 1 节的**标注判定**口径是两回事：
> 采集筛掉的是"连当清晰帧都不合格"的图，标注判的是"画面是否存在缺陷"。
